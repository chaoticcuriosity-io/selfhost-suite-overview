# Self-Hosted Software Suite — Capabilities Overview

A plain-language overview of a personal, self-hosted software suite that replaces a stack of paid SaaS
subscriptions across four domains: **dev & productivity, knowledge & notes, media & files, and
finance & home.**

It's a *menu, not a commitment* — each entry explains what the software does, what you can do with it,
and what paid service it replaces.

📖 **Read the rendered site:** https://chaoticcuriosity-io.github.io/selfhost-suite-overview/

The full content lives in [`index.md`](index.md). The site is published with GitHub Pages using the
built-in `jekyll-theme-cayman` theme (see [`_config.yml`](_config.yml)).
